# v0.0.8k notes

## Covered now
GlobalSetting (all 20 documented fields plus position 21 headphone phase seen on real SDS100 files), SearchCommon, CloseCall, Weather, WxSameList.

## Rules enforced (profile_schema.py)
- Choice fields accept only the specification's values; integer fields use canonical numbers in range (volume and squelch 0-15 for the handheld SDS100, priority interval 1-10, priority channels 1-100, digital threshold level 5-13, waiting time 0-1000, Close Call hold time 0-255).
- Reserved positions are read-only. SAME group names are limited to 16 ASCII characters (my limit, not stated in the specification) and FIPS codes are six digits or `------`.
- A changed record must keep its exact field count and row count. Records that are not edited are never judged, so a profile with an unusual layout elsewhere still exports other changes.
- The export guard re-derives the proposed file from the original plus validated edits and refuses if even one byte differs (line endings, unknown records, hand edits).

## Not verified on hardware
These ranges come from the specification and your real profile.cfg. The scanner's own acceptance of each setting is untested; see SETTINGS_EXPORT_TEST.md.

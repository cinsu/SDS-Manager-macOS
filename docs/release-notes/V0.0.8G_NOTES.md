# v0.0.8g — interim development build

Adds Favorites > Delete Favorites List… for the active saved local configuration.
Updates the local configuration manifest and removes the selected .hpd without writing to the scanner.

IMPORTANT: This build does NOT yet implement authoritative scanner synchronization (add/update/delete). Do not use Export to Scanner to test deletion: the current exporter does not yet remove scanner-only HPD files. This is an interim build, not a completed v0.0.8g milestone or release candidate.

Legacy code cleanup remains deferred until release candidate preparation.

## Update: create list moved into Add to Favorites; delete and add paths fixed (verified against real SDS100 files)
- Removed the standalone **Favorites → Create Favorites List…** command (an empty list can no longer be made).
- **Add to Favorites** now asks for the destination: an existing list, or a new list (name). A new list is created only
  when the channel selection is confirmed; cancel or any failure creates nothing. Conventional systems only for now.
- New list rows are built to match real Sentinel-written files: blank MyId/ParentId, a DQKs_Status record after the system
  header, system defaults (0/Off/Off/400/Auto/8), channel defaults (Off/2/0/Off/Auto/Off/On/Off/Off). Department location,
  channel modulation, tone/NAC/colour code and service type come from the database row (not from another list).
  No template list is needed any more.
- Quick key / number tag / Avoid / Priority are never inherited (two items cannot share a quick key or number tag).
  The new f_list.cfg row has the same 118-field shape as real rows: Location Control Off, Monitor On, everything else Off.
- Adding a channel to an EXISTING department no longer inherits the template channel's tone, modulation, service type,
  number tag or priority; those come from the database row; an invalid database value is left blank, never taken from another channel (modulation uses AUTO because it cannot be blank; a channel with no valid service type is refused). The
  export guard now allows modulation and service type to differ on an added channel.
- Delete Favorites List now also removes the f_list.cfg row, archives the .hpd and row permanently under
  scanner-configuration-backups/<configuration>/deleted-lists/, and drops the open working copy.
- Files, index and manifest are committed together and rolled back on failure.
- Tests: test_new_favorites_list.py uses real fixtures in test_fixtures/. See NEW_LIST_FROM_ADD_TEST.md.
  Export to Scanner still cannot add/remove list files.

# v0.0.8l notes

## What changed
Favorites List settings stored in favorites_lists/f_list.cfg can now be edited locally and exported.

## Rules (flist_settings.py)
- Per row: Name 1-64 printable ASCII without leading/trailing spaces; Location Control and Monitor On/Off; Quick Key and Number Tag Off or 0-99; ten Startup Keys and 100 system quick key flags On/Off.
- Filename, row order, field count and the trailing empty field never change here.
- A changed quick key / number tag / name may not collide with another list. Collisions that already exist on your scanner are left alone unless you change one of the colliding rows.
- The export guard (scanner_list_sync.assess_flist_replacement) now accepts edits to existing rows only if they pass the same rules, and still handles added and removed lists in the same export.

## Notes
- Number Tag range 0-99 is from Uniden's specification for list rows (channels use 0-999).
- Not verified on hardware: how the scanner treats a changed startup key or system quick key flag beyond the specification text. The test file lists what to check.

# v0.0.8i notes

## What changed
1. New Favorites List from a trunked system (Add to Favorites -> "Create new Favorites List").
2. Export of those lists (assess_new_hpd accepts Trunk, DQKs_Status, Site, BandPlan_P25/Mot, T-Freq, T-Group, TGID).
3. Export ends with `os.sync()`; dialog explains safe unmount.

## Layout (verified against a Sentinel-written Palmetto 800 list; test_new_trunk_list.py compares it row for row)
- Trunk (22): name, system type from the database, TGID format IDAS (database value only for NXDN), defaults elsewhere.
- DQKs_Status: all Off. Site (19): name, lat, lon, range, modulation, NAC, filter from the database; Circle; defaults 400/Auto/8.
- BandPlan: database rows kept (SiteId blanked). A P25 Standard site with none gets the default row Sentinel wrote.
- T-Freq (9): frequency, `Srch`/audio option from the database; channel number 0 for P25 Standard, database value otherwise.
- T-Group (10) and TGID (17): name, TGID, audio type, service type, TDMA slot from the database; defaults elsewhere.
- Refused (nothing created): invalid frequency/TGID/audio type/service type, Rectangle locations, unsupported system type, a site with no frequencies, a list without a talkgroup.

## Not verified on hardware
Only P25 Standard matches a real native file. Motorola/EDACS band types, MotoTrbo/DMR/LTR/NXDN channel numbers and band plans follow the database and Uniden's spec but have no real native sample here. Test P25 first.

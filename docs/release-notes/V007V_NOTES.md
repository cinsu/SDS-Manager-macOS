# v0.0.7v — profile ServiceType foundation

No GUI service-type editor is added yet; this is backend support only. Existing QuickKeys and offline location export behavior is unchanged. GlobalSetting editing remains pending. Physical scanner verification of ServiceType edits has not been performed.

# v0.0.7q preview — configuration filename indicator

This is a focused preview of the filename indicator, NOT the multi-HPD export release.

1. Launch the application and choose File > Open Scanner Configuration.
2. Open a previously saved local scanner configuration.
3. Verify the bottom status bar permanently displays `Configuration: <folder name>`.
4. Hover over the label to see the complete local configuration path.
5. Edit one native Favorites channel; after the next five-minute autosave interval, the label should show `*` for unsaved changes. Saving should clear it.

No scanner export is required for this GUI test.

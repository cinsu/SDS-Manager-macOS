# Physical test: display and hardware settings

1. Scanner Settings -> Global, Display and Hardware Settings. Look through the new tabs; values should match what the scanner shows.
2. Change a few visible things: Owner info line 1, Backlight brightness, Key light time, Time zone or Daylight saving, Colour mode, Replay duration. Save and confirm the review list.
3. File -> Export to Scanner (only profile.cfg should be replaced). After "File Verified", unmount, wait for "safe to remove", power the scanner off and on.
4. Check the owner message at start-up, brightness, clock, colours and replay setting. Change them back and export again.
If anything is wrong send EXPORT_RECOVERY.txt from ~/.local/share/sds100-database-favorites-manager/scanner-backups/<newest>/ and the card's profile.cfg.

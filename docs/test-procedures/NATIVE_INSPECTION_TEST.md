# v0.0.6v GUI test — one test at a time

1. Launch test-launch.sh and connect the SDS100 in Mass Storage mode.
2. File → Preview Scanner Export (Read-only)…
3. Choose saved configuration `unchanged` and the scanner volume.
4. Verify the new NATIVE FILE INSPECTION — READ ONLY section appears, with counts, warnings and Export action: DISABLED.
5. Paste only the new inspection section for review.

Inspection is intentionally limited to lossless byte decoding and selected header presence. It does not establish native write compatibility.

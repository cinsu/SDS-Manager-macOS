# v0.0.6y — Native Favorites Multi-Field Probe

Run File → Preview Scanner Export (Read-only)… with configuration `unchanged` and select the scanner BCDx36HP folder. Paste the NATIVE FAVORITES MULTI-FIELD PROBE section. The probe changes up to two text columns on one record per eligible record kind per file, entirely in memory, then checks all untouched lines, column counts, line endings and byte-exact restoration. These artificial field values are NOT valid native SDS100 values and this is NOT edited-file compatibility validation. Scanner export remains disabled.

# v0.0.6x — Native Favorites edit probe (read only)

1. Run `test-launch.sh` and choose File → Preview Scanner Export (Read-only).
2. Choose saved configuration `unchanged` and the SDS100 Mass Storage drive.
3. Paste only NATIVE FAVORITES EDIT PROBE — READ ONLY section.

The probe edits one name field per eligible local Favorites HPD in memory, checks unchanged records and exact byte restoration, and never writes local or scanner files. This does not establish scanner serialization compatibility.
